# Roadmap

This roadmap is intentionally limited to research-ledger governance and structure. Research data should not be added until the governance base is reviewed.

## Milestone 0: Project Governance

Goal: establish a small, reviewable operating model for research tracking.

### Ledger Repository Issues

1. [#1 Create research ledger governance documentation](https://github.com/Shoko-official/llm-systems-research-ledger/issues/1)
2. [#2 Add research issue and MR templates](https://github.com/Shoko-official/llm-systems-research-ledger/issues/2)
3. [#3 Add minimal validation, CI, and ledger folder structure](https://github.com/Shoko-official/llm-systems-research-ledger/issues/3)

### Execution Order

1. Complete issue #1 before adding templates or structure.
2. Complete issue #2 before creating research contribution PRs.
3. Complete issue #3 before adding any sources or claims.
4. Return to the global sequence before starting paper work.

No research data should be added during Milestone 0.

## Acceptance Criteria

Milestone 0 is complete when:

* the repository role is documented;
* claim and source rules are documented;
* issue and MR/PR templates exist;
* minimal validation commands exist;
* minimal CI exists;
* initial folders for sources, claims, citations, schemas, scripts, and tests exist;
* no real sources or claims have been added.

## Later Milestones

Later milestones are placeholders until Milestone 0 is complete.

Expected sequence:

1. Define a minimal source record format.
2. Define a minimal claim record format.
3. Define evidence status values.
4. Add validation for source and claim records.
5. Add a small seed set of approved sources.
6. Add a small seed set of approved claims.
7. Connect paper citation needs to ledger records.

Any schema work must happen in a dedicated issue with validation.
